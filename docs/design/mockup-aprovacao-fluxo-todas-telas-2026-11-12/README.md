# CoreFlow · mockup de aprovação Fluxo

Galeria local de referências visuais para revisar a aplicação da direção Fluxo a todas as áreas do app, incluindo a overlay das pílulas.

Abra `index.html` em um navegador. As seis pranchas PNG estão em `pranchas/`; não há CDN, fonte remota ou dependência.

## O que aprovar

- Hierarquia, composição, contraste e superfícies das cinco abas principais.
- Tratamento visual das práticas, sessões e diálogos.
- Referências para agenda, nota, lembrete, medição de BPM, Galaxy Watch e detalhes de conquistas.
- Estados mini, compacto, pausado e expandido da pílula, mais a confirmação de cancelamento e a saída segura do Vácuo.

As pranchas são conceitos gerados para revisão visual; textos pequenos, BPM, conexão e números dentro delas podem ser ilustrativos. A galeria inventaria os conteúdos existentes e aponta para o protótipo interativo aprovado. Aprovação visual não muda textos, dados, IDs, rotas, armazenamento, exercícios, protocolos ou integração com o Galaxy Watch.

O [protótipo Fluxo completo aprovado](../prototipo-fluxo-completo-2026-11-12/index.html) permanece disponível para percorrer os estados interativos já demonstrados.
