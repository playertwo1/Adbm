# CoreFlow 1.1.51

## O que mudou

- Renovada a camada visual das telas Hoje, Programas, Pausas, Evolução, Perfil, Vácuo, Discreto e onboarding: grafite com tom de floresta, ações em sálvia, cores de apoio suavizadas, superfícies e contornos mais calmos e navegação inferior opaca.
- Alinhadas as cores entre a interface WebView e os componentes nativos Android: player Compose, janela flutuante, barras do sistema, recursos do ícone e módulo Wear OS.
- Corrigido o editor de Perfil: o modal agora é movido para `document.body` antes de abrir, evitando que o `transform` da aba contenha o posicionamento fixo e esconda o diálogo.
- Mantidos a navegação, a ordem do conteúdo, os IDs dos programas, o armazenamento, o histórico e o protocolo dos treinos. As ilustrações e a marca do produto foram preservadas; não foram adicionadas imagens externas ou geradas.
- README reorganizado com capturas reais do aplicativo, arquitetura, instalação e detalhes desta versão.

## APKs

- `app-release.apk`: aplicativo para celular Android.
- `wear-release.apk`: módulo complementar Wear OS para relógios compatíveis; precisa ser instalado separadamente.

Versão: **1.1.51** (`versionCode 51`).

## Verificação

- `diagnostics/e09-2-profile.test.cjs`: reproduziu o modal oculto antes da correção e passou após a mudança.
- `diagnostics/ci-policy.test.cjs`: verifica que o artefato do workflow inclui as notas da versão selecionada.
- `diagnostics/e07-programas.test.cjs`: o extrator de constantes aceita LF e CRLF, usados respectivamente no runner Linux e no checkout Windows.
- `bash scripts/check.sh`: diagnósticos, equivalência dos arquivos HTML, testes unitários Android e builds debug do app e Wear passaram.
- Telas Hoje, Programas, Pausas, Evolução, Perfil, Vácuo, Discreto, onboarding, editor de Perfil, player e overlay conferidos no emulador Android API 36.

## Limites desta entrega
