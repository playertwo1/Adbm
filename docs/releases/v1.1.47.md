# CoreFlow 1.1.47

## O que mudou

- Cancelar encerra a sessão de forma consistente no guia web e no overlay Android, mantendo separada a saída segura durante a retenção de Vácuo.
- Imagens locais dos exercícios de Corpo aparecem no overlay expandido.
- A orientação e as animações de Respiração acompanham o relógio único do motor nativo.
- Controles de pausa, retomada e cancelamento permanecem alinhados nos modos flutuantes.

## Arquivos

- `app-release.apk`: aplicativo Android para celular.
- `wear-release.apk`: aplicativo complementar Wear OS/Galaxy Watch.
- `README.md`: recursos, downloads e manual do relógio.

Versão: **1.1.47 (versionCode 47)**. Os APKs usam a mesma assinatura da versão 1.1.46 para permitir a atualização sem reinstalação dos dados.
