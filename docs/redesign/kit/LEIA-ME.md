# Como usar este kit (para você, Rafael)

1. Copie esta pasta para o repositório em `docs/redesign/kit/`.
2. Preencha em `VISAO.md` a linha `<PREENCHER: ...>` com onde está a referência
   visual aprovada (DESIGN.md, screenshots ou commit).
3. Deixe o emulador aberto, com Maestro funcionando no PowerShell.
4. No Codex Desktop, ajuste a aprovação para permitir comandos no workspace
   (adb, gradlew, maestro), senão ele trava pedindo aprovação a cada passo.
5. Cole o conteúdo de `00_MAE.md` no Codex.
6. Ao fim de cada missão, revise e diga "siga para a próxima missão".
   Nos checkpoints (M2, M5, M6), responda com a sua escolha.
7. Dica: uma sessão nova do Codex por missão economiza contexto. O PROGRESS.md
   garante a continuidade.
