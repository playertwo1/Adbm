# E15 Bracing Implementation Plan

> **For agentic workers:** Implement each checkpoint in order and keep this checklist synchronized with `ROADMAP.md` and `docs/roadmap/execucao.md`.

**Goal:** Deliver the eight-week seated/standing Bracing program from the supplied source while preserving existing program IDs, stored history, WebView safety, Android timer, and Wear protocol.

**Architecture:** Keep the canonical exercise catalog and week matrix in the existing HTML JavaScript, then route guide, detail view, and the current workout player through that data. Add only backward-compatible progress and split-session fields; do not create a second timer or change the native payload unless a regression proves it necessary.

**Tech Stack:** HTML/JavaScript, Node.js `node:test`-style diagnostics using `assert`/`vm`, Android WebView, existing Kotlin workout service and Wear relay.

**Spec:** `docs/roadmap/bracing-8-semanas-v2.md`; prescriptions are sourced verbatim from `docs/roadmap/fontes/TREINO_BRACING_8_SEMANAS.md`.

## Global Constraints

- Preserve program IDs `'1'` Bracing, `'2'` Kegel, and `'3'` Vacuum.
- Bracing has one prescribed session per day and five distinct practice days per week.
- Bracing exercises use a stable chair or standing, with no floor positions, equipment, breath holding, or maximum effort instructions.
- Keep `index.html` byte-identical to `app/src/main/assets/index.html`.
- Preserve older data and make new migration fields additive and idempotent.
- Reuse the existing Android workout service and Wear protocol.
- Keep image approval, user visual acceptance, and physical-device gates pending until evidence exists.

## Review Focus

- Exact per-week order, volume, sides, rests, and two laps in week 8: `e15-bracing-catalog.test.cjs`.
- Invalid week inputs and legacy session-number behavior: `e15-bracing-catalog.test.cjs`.
- Reduced practice, duplicate dates, and progression eligibility: `e15-bracing-progression.test.cjs`.
- Legacy snapshot preservation and idempotent migration: `e15-bracing-progression.test.cjs` and `progress-persistence.test.cjs`.
- Resume/session interruption, native payload compatibility, and HTML parity: `e15-bracing-integration.test.cjs`, `session-engine.test.cjs`, `e14-bracing-pausas-floating.test.cjs`.
